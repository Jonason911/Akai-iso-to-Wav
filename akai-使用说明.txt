================================================================
 akai —— Akai 采样盘镜像一键解包工具
 把 CD 镜像（iso / img / cdr / bin）丢桌面，终端输入 akai，
 自动判定封装、提取采样、合并左右声道，输出可直接用的 WAV。
================================================================

----------------------------------------------------------------
一、它能做什么
----------------------------------------------------------------
你手上有一张老采样盘的镜像（Akai S1000/S3000、MPC、E-mu 等
格式都可能是），但：

  · macOS 双击挂不上
  · 解压软件打不开
  · 转换工具报 Unknown Format

这些多半不是镜像坏了，而是工具不认 Akai 自己那套非 ISO9660
的分区结构。akai 就是为这种情况准备的：先判定镜像到底是什么
封装，再选对应的路子把采样扒出来。

----------------------------------------------------------------
二、环境准备
----------------------------------------------------------------
◆ 操作系统
  macOS（脚本默认扫 ~/Desktop，并兼容 iCloud 同步的真实路径
  ~/Library/Mobile Documents/com~apple~CloudDocs/Desktop）。
  Linux / Windows 需改开头的 DESK 变量。

◆ 必装
  Python 3（macOS 自带，或 brew install python3）

◆ 主提取器（强烈建议装）
  python3 -m pip install --user smpl-extract
  作用：自动合并 L/R 成立体声、保留 loop 点和 root key。
  脚本检测不到时会自动尝试安装。

◆ 备用提取器（可选）
  brew install libgig
  装完会有 akaiextract 命令。主提取器失败时自动兜底。
  注意：它不合并 L/R，脚本会在导出后自动补合并。

◆ 命令行基础
  会打开"终端"、能敲回车即可。

----------------------------------------------------------------
三、安装（只需做一次）
----------------------------------------------------------------
1) 把 akai 脚本放到 ~/bin 并给执行权限：

     mkdir -p ~/bin
     cp ~/Downloads/akai ~/bin/akai
     chmod +x ~/bin/akai

2) 把 ~/bin 加进 PATH：

     echo 'export PATH="$HOME/bin:$PATH"' >> ~/.zshrc
     source ~/.zshrc

   想全局安装（所有用户可用、不用配 PATH）：

     sudo cp ~/Downloads/akai /usr/local/bin/akai
     sudo chmod +x /usr/local/bin/akai

3) 验证：

     which akai

   有输出就装好了。装好后，下载文件夹里的那个原件可以随便删
   或归档，真正被调用的是 ~/bin/akai 这一份。

----------------------------------------------------------------
四、使用方法
----------------------------------------------------------------
1) 把镜像文件放到桌面（支持 .iso / .img / .cdr / .bin）
2) 打开终端，输入：

     akai

3) 回车，等它跑完。全过程六步：
     ① 定位镜像  ② 判定封装  ③ 检查工具
     ④ 导出采样  ⑤ 合并声道  ⑥ 打印报告

4) 结果在桌面：
     <镜像名>_wav/          未做声道合并时的输出
     <镜像名>_wav_stereo/   做了 L/R 合并时的输出（以报告为准）

报告会告诉你：WAV 总数、单声道/立体声各多少、占用空间、
顶层分组目录。直接把输出文件夹拖进 DAW 就能用。

◆ 桌面上有多个镜像时会列出来让你选编号，直接回车默认选 1。

----------------------------------------------------------------
五、它是怎么判定的（原理）
----------------------------------------------------------------
靠两个信号：文件大小对扇区尺寸取余 + CD001 签名出现的位置。

  CD001 @ 32769，且大小能被 2048 整除
      → 标准 ISO9660，直接提取
  CD001 @ 37649，且大小能被 2352 整除
      → 裸扇区 dump，先转 2048 再提取
  两个位置都找不到 CD001
      → Akai 原生盘，直接提取，无需转换

第二种会在桌面生成 <镜像名>-2048.iso 中间文件。

----------------------------------------------------------------
六、注意事项（重要）
----------------------------------------------------------------
1) 【会覆盖输出目录】
   每次运行前会 rm -rf 掉 <镜像名>_wav 和 <镜像名>_wav_stereo
   再重建。别把别的东西放进去，也别把重要文件命名成这个。

2) 【只扫桌面这一层】
   镜像放别的文件夹它找不到。放桌面，或用 mdfind 先定位。

3) 【脚本文件本身别加镜像后缀】
   扫描的是 iso/img/cdr/bin。你要是把脚本改名成 akai.bin
   放桌面，它会被当成镜像让你选编号。保持叫 akai 就行。

4) 【WAV 不带 loop 标记】
   Akai 的 loop 点不会写进导出的 WAV。当素材拖进工程用没问题；
   要在采样器里当乐器弹，loop 点得在 DAW 里重设。

5) 【混合模式盘解不了】
   有些盘的 loop 在 CD 音轨里（.bin/.cue 常见），数据区只有
   单发音。脚本导出 0 个文件时会提示这件事——那不是脚本坏了，
   需要 XLD / EAC 单独抓音轨。

6) 【单声道文件不一定有问题】
   鼓库里 kick、snare、hat 这类单发音本来就是单声道。报告里
   出现单声道是正常的，不用强行合并。

7) 【镜像体积 ≠ 输出体积】
   505MB 的镜像出 143MB WAV 很常见。Akai 盘常留空分区，
   只要采样数量级合理（几十到几百个）就是读全了。

----------------------------------------------------------------
七、故障排查
----------------------------------------------------------------
提示"桌面没有找到 iso/img/cdr/bin 镜像"
  → 确认文件在桌面，且后缀是这四种之一

提示"没有可用工具"
  → 手动跑 python3 -m pip install --user smpl-extract
    或 brew install libgig

导出 0 个 WAV
  → 多半是混合模式盘（见注意事项 5），用 XLD 抓音轨

smpl_extract 报 "is not a file"
  → 脚本已内置三种参数写法依次尝试，仍失败会退回 akaiextract。
    若手动跑遇到，改用：cd 目标目录 && python3 -m smpl_extract
    export /完整路径/镜像.iso

想确认盘有没有读全
  → 用 akaiextract 独立跑一遍做交叉验证，件数应≈
    单声道数 + 立体声数×2
